# Tooltip Overhaul

A complete visual refresh for Minecraft tooltips, completely replacing the vanilla tooltip system with a clearer and polished layout.

This mod is _client-side only_, no dependencies required. Just drop it in your mods folder and start playing! _(Fabric users need ModMenu to open the config screen)_

Tooltip Overhaul is **highly customizable**. You can easily replicate the look of the vanilla tooltips or customize them to be as extravagant as possible, you have the complete creative freedom. As always, every tooltip, more modern, sharper, clearer.
